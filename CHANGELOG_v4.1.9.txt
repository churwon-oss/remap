ReMap v4.1.9 변경 기록
====================

1. Windows AI 설정 화면 스크롤 개선
----------------------------------
- AI 설정 본문 전체를 세로 스크롤 가능한 구조로 변경했습니다.
- 오른쪽에 항상 확인할 수 있는 세로 스크롤바를 추가했습니다.
- 고급 설정을 펼치면 사용 모델, 모델 새로고침, 안내문, 저장 키 삭제, 닫기 버튼까지 모두 스크롤하여 확인할 수 있습니다.
- 고급 설정을 펼칠 때 해당 영역이 보이도록 자동으로 아래쪽으로 이동합니다.
- AI 설정 창을 사용자가 확대·축소할 수 있도록 조정했습니다.
- 작은 화면과 Windows 디스플레이 배율 125~150%에서도 하단 항목이 가려지지 않도록 구성했습니다.

2. 끊겨 보이던 그림자와 카드 외곽 수정
--------------------------------------
- 메인 서버 카드와 AI 설정 카드 뒤에 따로 배치하던 어두운 오프셋 그림자를 제거했습니다.
- 분리된 그림자 대신 하나의 라운드 외곽 셸 안에 밝은 카드를 넣는 계층형 구조로 변경했습니다.
- 카드 오른쪽과 아래쪽에서 그림자가 사각형처럼 끊겨 보이던 현상을 줄였습니다.
- 외곽 색상을 너무 어두운 검정 계열이 아닌 부드러운 네이비·블루 계열로 조정했습니다.
- 학생 접속 카드, 서버 상태 요약 카드, 네트워크 카드도 같은 계층형 라운드 구조로 통일했습니다.
- 기존 그라데이션 버튼, 라운드 입력창, 굵은 글꼴과 교사 화면 디자인 언어는 유지했습니다.

3. 유지된 기능
--------------
- 학생용 ReMap 대표 캐릭터 .lnk 바로가기 생성
- 현재 접속자·미제출자 정리와 30초 상태 점검
- 같은 방·같은 게임·같은 브라우저의 임시 참가자 ID 기반 재접속 복구
- 다음 게임 준비 시 현재 연결 참가자 유지
- 연속 게임 시상식 결과 갱신
- 보물상자 현황 글씨 대비 개선
- Windows 인증서 저장소 및 학교망 인증서 호환 모드
- Gemini 모델 자동 조회와 고급 설정
- 서버 정상 종료 처리
- WebSocket 위치 전송 최적화
