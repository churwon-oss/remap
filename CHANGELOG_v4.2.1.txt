ReMap v4.2.1 변경 기록
========================

1. Windows 실행기
- '교사 화면 열기'를 '교사용 화면 열기'로 변경
- 'PC용 캐릭터 바로가기'를 '학생용 바로가기 생성'으로 변경
- 밝은 메인 카드의 네 모서리에 보이던 어두운 배경 노출 제거
- 대회 제출용 프로그램에서 작성자·학교·이메일 표시 제거
- 시작 화면에 연구 작품명과 대상 학년을 간결하게 표시

2. 교사용 웹 화면
- QR 영역의 'PC용 바로가기'와 'QR 이미지 저장' 삭제
- 학생 접속 주소의 '주소 복사'만 유지
- 설정 창에서도 학생 접속 주소 복사만 제공

3. 학생 문제 입력 화면
- 문제 카드의 100% 고정 높이를 제거하여 내용 높이만 사용
- 4번 보기 아래에 다음 문제가 짧은 간격으로 바로 이어짐
- '문제 1', '문제 2', '문제 3' 제목의 가독성 개선

4. 제출 자료
- '먼저 읽어주세요'를 통합한 'ReMap 사용 매뉴얼.pdf' 제공
- 로컬 EXE와 Render 온라인 시험판의 역할을 매뉴얼에 함께 안내
