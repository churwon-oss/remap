ReMap v4.1.8 변경 기록
====================

1. Windows 실행 화면 디자인 개선
--------------------------------
- 교사 화면의 시각 언어를 참고해 Windows 실행기를 프리미엄 대시보드 형태로 재구성했습니다.
- 네이비·블루·퍼플 배경 그라데이션과 밝은 화이트·블루 카드 조합을 적용했습니다.
- 라운드 카드, 다층 테두리, 오프셋 그림자, 상단 강조선, 그라데이션 핵심 버튼을 적용했습니다.
- 글꼴을 Arial·Malgun Gothic 계열로 통일하고 제목·상태·버튼 글씨를 더 굵고 크게 조정했습니다.
- 실행 화면에 서버 상태, 학생 네트워크 IP, AI 상태를 한눈에 볼 수 있는 요약 카드를 추가했습니다.
- 실행 화면에서 학생 접속 QR을 바로 볼 수 있도록 QR 미리보기를 추가했습니다.
- 교사 화면 열기, PC용 캐릭터 바로가기, 주소 복사, 저장 폴더, 실행 로그를 한 화면에 정리했습니다.
- 대표 캐릭터 앞에 표시되던 버전 배지를 제거하고 버전은 화면 하단에만 표시합니다.
- 학교 PC 안내 아래 다음 정보를 추가했습니다.
  작성자: 서울시교육청 교사 김철원
  문의: churwon@sen.go.kr

2. 학생 PC용 캐릭터 바로가기 개선
----------------------------------
- 기본 학생 PC 접속 파일을 .url에서 실제 Windows Shell Link인 .lnk로 변경했습니다.
- 생성되는 'ReMap 수업 시작.lnk' 파일 자체에 ReMap 대표 캐릭터 아이콘을 지정합니다.
- 학생 PC에서 별도의 BAT 설치 파일을 실행하지 않아도 됩니다.
- 현재 실행 PC에서 선택한 내부 IP, 실제 포트, 방 코드를 바로가기에 반영합니다.
- ReMap_Student.ico와 QR 이미지, 접속 주소, HTML 대체 접속 파일을 함께 생성합니다.
- 이전 버전의 빈 문서 .url과 설치용 BAT가 남아 있으면 새 자료 생성 시 자동 삭제합니다.
- Windows 로컬 교사 화면의 [PC용 바로가기] 다운로드도 가능한 경우 .lnk를 우선 제공합니다.
- Render와 비 Windows 개발 환경에서는 기존 .url 호환 방식을 유지합니다.

3. 유지된 기능
--------------
- 현재 접속자·미제출자 정리와 30초 상태 점검
- 같은 방·같은 게임·같은 브라우저의 임시 참가자 ID 기반 재접속 복구
- 다음 게임 준비 시 현재 연결 참가자 유지
- 연속 게임 시상식 결과 갱신
- 보물상자 현황 글씨 대비 개선
- Windows 인증서 저장소 및 학교망 인증서 호환 모드
- Gemini 모델 자동 조회와 고급 설정
- 서버 정상 종료 처리
- WebSocket 위치 전송 최적화
