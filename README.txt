ReMap v4.1.9
=============

ReMap(Remind Map)은 학생이 배운 내용을 직접 문제로 만들고, 게임 맵에서 친구를 만나
퀴즈 배틀을 진행하는 수업용 실시간 웹게임입니다.

이 배포본은 사용 목적에 따라 세 가지로 나뉩니다.

1. ReMap_v4.1.9_Windows_Portable_EXE.zip
   - 일반 교사용
   - Python 설치 불필요
   - ZIP 전체를 압축 해제한 뒤 ReMap_Server.exe 실행

2. ReMap_v4.1.9_Developer_Python.zip
   - 설계자·개발자용 전체 소스
   - Python으로 실행, 수정, 검사 가능

3. ReMap_v4.1.9_Render_GitHub.zip
   - GitHub / Render 배포용
   - ZIP 내부 파일을 GitHub 저장소 최상위에 업로드


이번 버전의 핵심 수정
--------------------

- 현재 접속자·미제출자 정리
  - 학생이 정상 퇴장하거나 WebSocket 연결이 닫히면 현재 참가자와 미제출자 수에서 즉시 제외
  - 문제 입력 화면과 게임 화면에서 20초마다 존재 신호 전송
  - 서버가 30초 간격으로 상태를 점검하여 강제 종료·인터넷 단절로 남은 미제출 기록 자동 정리
  - 보물상자 풀이 현황의 전체 인원도 현재 연결 학생 기준으로 계산

- 같은 게임 재접속 복구
  - 개인정보가 아닌 무작위 임시 참가자 ID와 재접속 토큰 사용
  - 같은 브라우저·같은 방·같은 게임 회차·유효한 토큰일 때만 기존 참가자로 복구
  - 닉네임, 팀/색상, 제출 문제, 확정 점수, 보물상자 기록 유지
  - 다른 기기·다른 브라우저·다른 회차는 새 참가자로 처리
  - 배틀 도중 연결이 끊기면 미확정 배틀만 취소하여 상대 학생이 멈추지 않도록 처리

- 다음 게임 참가자 유지
  - [다음 게임 준비]를 눌러도 현재 연결된 기존 학생의 WebSocket과 참가자 수 유지
  - 점수·문제 제출·배틀·보물상자·위치·시상식 상태만 새 게임 기준으로 초기화
  - 교사 화면에는 기존 접속자 수가 유지되고 전원이 새 게임 미제출자로 표시
  - 학생 화면은 자동으로 새 문제 입력 화면으로 이동

- 보물상자 현황 가독성
  - 교사 화면의 "4/8명 풀이" 글씨를 검정에 가까운 진한 네이비로 변경
  - 보조 글씨도 더 진한 색과 굵기로 조정

- 연속 게임 시상식 오류 수정
  - 첫 게임 뒤 같은 방에서 다시 게임했을 때 이전 게임의 시상대가 남던 문제 수정
  - 새 학생이 참여한 두 번째 게임에서도 현재 참가자와 현재 점수로 결과를 새로 계산
  - 전체 개인 순위와 개인 시상대가 동일한 종료 스냅샷을 사용
  - 새 게임 시작 시 이전 시상식 스냅샷 삭제
  - 시상식 페이지 캐시 방지

- Windows 교사용 실행기
  - 내부 IP 자동 감지 및 선택
  - 8000번 포트 사용 중이면 다음 사용 가능한 포트 자동 선택
  - 교사 화면 자동 실행
  - 학생 접속 주소 표시 및 복사
  - CustomTkinter 기반 실행 화면을 교사 화면과 같은 프리미엄 대시보드 형태로 전면 재구성
  - Arial·Malgun Gothic 계열의 굵고 읽기 쉬운 글꼴, 네이비·블루·퍼플 그라데이션 적용
  - 라운드 카드, 다층 테두리, 입체 그림자, 상태 요약 카드, QR 미리보기 적용
  - 대표 캐릭터 앞의 버전 배지를 제거하고 버전 정보는 하단에만 정리
  - 학교 PC 안내 아래 작성자·문의 정보 표시
  - AI 설정은 상단 [⚙ AI 설정] 팝업으로 분리하여 실행 화면을 단순화
  - 학생이 실제로 누르는 ReMap 수업 시작.lnk 파일 자체에 대표 캐릭터 아이콘 적용
  - 별도 BAT 설치 없이 Windows Shell Link를 즉시 생성하고 QR·HTML 대체 접속 파일 함께 제공
  - 서버 정상 종료 및 데이터 폴더 열기
  - 창 닫기 시 보조 창과 서버를 함께 정리하고, 종료 지연 시 자동 마무리하여 실행창이 남는 현상 방지

- Gemini AI 설정
  - Windows EXE 상단 [⚙ AI 설정]에서 API 키를 입력
  - Windows 인증서 저장소를 우선 사용하여 학교·교육청 HTTPS 검사 인증서에 대응
  - Python 3.13의 Missing Authority Key Identifier 오류는 인증서 검증을 유지한 학교망 호환 모드로 자동 재시도
  - 연결 성공 시 Windows 인증서 저장소 / 학교망 인증서 호환 모드 등 실제 방식을 표시
  - 교사 웹 화면의 [⚙ AI 설정]에서도 변경 가능
  - 기본 화면에는 모델 선택란을 표시하지 않고 API 키와 연결 테스트만 제공
  - 사용 모델은 API 키에 따라 자동 선택하며, 필요할 때만 [고급 설정]에서 확인·변경
  - API 발급 페이지와 연결 테스트 제공
  - API 키별 generateContent 지원 모델만 불러와 고급 설정 드롭다운으로 제공
  - 처음 연결하거나 기존 모델이 사라진 경우 ReMap 문제 검토에 적합한 Flash 계열 모델을 자동 선택
  - 모델 목록은 Google Gemini models.list 결과를 기준으로 하므로 모델명을 직접 외울 필요가 없음
  - 기본값은 실행 중에만 유지
  - Windows에서 [이 PC에 저장]을 선택한 경우 현재 Windows 사용자 계정에 묶어 암호화 저장
  - AI 연결 실패가 게임과 WebSocket 진행을 중단시키지 않음
  - Render는 GEMINI_API_KEY 환경변수 사용

- WebSocket 최적화
  - 학생 이동 전송 최대 20Hz
  - 학생 위치 방송 최대 15Hz
  - 교사 위치 방송 최대 8Hz
  - 이동 시 전체 상태 대신 변경된 좌표만 전송
  - 순위·로그·보물 현황은 이벤트 발생 및 일정 간격으로 갱신
  - 학생 패킷에서 교사 전용 관리 데이터 제외
  - 소켓별 전송 잠금 및 교사 화면 좌표 보간


A. Windows 일반 교사용
----------------------

사용 파일:
  ReMap_v4.1.9_Windows_Portable_EXE.zip

실행:
1. ZIP을 다운로드합니다.
2. 반드시 ZIP 전체를 압축 해제합니다.
3. 압축을 푼 폴더의 ReMap_Server.exe를 더블클릭합니다.
4. 서버가 준비되면 교사 화면이 자동으로 열립니다.

주의:
- ReMap_Server.exe만 따로 옮기면 실행되지 않습니다.
- app, launcher, runtime 폴더와 EXE가 같은 폴더에 있어야 합니다.
- 학생 PC·모바일과 교사 PC는 같은 내부망에 연결되어야 합니다.
- 학생과 같은 네트워크의 IP를 실행기에서 선택합니다.
- IP가 바뀌면 PC용 바로가기를 다시 만듭니다.

학생 접속:
- 모바일·태블릿: 교사 화면 또는 실행기의 QR 촬영
- 실습실 PC: [PC용 캐릭터 바로가기]로 만든 ReMap 수업 시작.lnk 실행
- 생성되는 .lnk 파일 자체가 ReMap 대표 캐릭터 아이콘으로 표시되며 별도 BAT 설치가 필요하지 않습니다.
- 학교 보안 설정이 바로가기 실행을 제한하면 함께 생성된 "바로가기 오류 시 여기를 눌러 수업에 참여하세요.html" 실행

중요:
- 이전 버전에서 만든 .url 및 설치용 BAT는 삭제하고 v4.1.9에서 새로 만드세요.
- 새 바로가기는 현재 실행 PC에서 선택한 IP와 실제 포트를 자동 반영합니다.
- ReMap 수업 시작.lnk와 ReMap_Student.ico는 같은 학생 접속 폴더에 함께 보관하세요.

데이터 저장 위치:
  %APPDATA%\ReMap\
    결과\
    학생문제\
    학생 접속\
    로그\

문제가 생기면:
- 먼저 %APPDATA%\ReMap\로그\ReMap_Server.log를 확인합니다.
- 배포 폴더의 ReMap_문제해결용.bat로 콘솔 진단 실행도 가능합니다.
- 학교망에서 인증서 오류가 발생하면 [⚙ AI 설정]의 [연결 테스트]를 다시 실행합니다.
- 성공 메시지에 "Windows 인증서 저장소" 또는 "학교망 인증서 호환 모드"가 표시되면 정상입니다.
- 그래도 실패하면 전산 담당자에게 학교 HTTPS 검사 루트 인증서가 Windows의 '신뢰할 수 있는 루트 인증 기관'에 설치되어 있는지 확인해 달라고 요청합니다.
- ReMap은 인증서 검증을 완전히 끄지 않으며, Gemini API 자체가 차단된 망은 전산 담당자의 도메인 허용이 필요합니다.


B. 설계자용 Python 실행
----------------------

권장: Python 3.12 이상

웹 서버 개발 설치:
  python -m pip install -r requirements.txt

Windows 실행기 소스까지 실행할 때:
  python -m pip install -r requirements-windows.txt

Windows 실행:
  run_server.bat

Mac/Linux 실행:
  ./run_server.sh

교사 화면:
  http://127.0.0.1:8000/teacher

검사 도구 설치:
  python -m pip install -r requirements-dev.txt

검사:
  python -m py_compile app/main.py app/runtime_config.py app/gemini_transport.py launcher/remap_launcher.py
  python -m pytest -q
  python tests/check_embedded_js.py

30명 로컬 부하 검사 예시:
  python tests/load_test_local.py --base-url http://127.0.0.1:8765 --clients 30 --duration 5

Windows용 PyInstaller one-folder 빌드가 필요한 경우:
  build_windows.bat

Node.js가 없는 PC에서는 JavaScript 문법 검사만 건너뛰고 빌드를 계속하도록 수정되어 있습니다.


C. GitHub / Render 배포
----------------------

사용 파일:
  ReMap_v4.1.9_Render_GitHub.zip

1. ZIP 내부 파일을 GitHub 저장소 최상위에 올립니다.
2. Render에서 저장소를 연결합니다.
3. render.yaml을 사용하거나 아래 명령을 설정합니다.

Build Command:
  pip install -r requirements.txt

Start Command:
  uvicorn app.main:app --host 0.0.0.0 --port $PORT --ws-ping-interval 20 --ws-ping-timeout 60 --no-access-log

환경변수:
  REMAP_RUNTIME=render
  REMAP_VERSION=4.1.9
  GEMINI_API_KEY=발급받은 키       (AI 검토 사용 시)
  GEMINI_MODEL=사용할 모델 ID     (선택, 미지정 시 API 키에서 자동 선택)

Render에서는 교사 화면에 API 키를 직접 입력하지 않고 서버 환경변수를 사용합니다.
서버 재시작 시 메모리 기반 방과 진행 중 상태는 유지되지 않으므로 게임 종료 후 결과와
학생 문제 파일을 바로 다운로드하는 것이 안전합니다.
