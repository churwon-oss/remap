ReMap v4.1.8 시작 안내
======================

일반 교사:
- ReMap_v4.1.8_Windows_Portable_EXE.zip을 압축 해제
- ReMap_Server.exe 더블클릭

설계자·개발자:
- python -m pip install -r requirements.txt
- run_server.bat 또는 run_server.sh 실행

Render 배포:
- ReMap_v4.1.8_Render_GitHub.zip 내부 파일을 GitHub 저장소 최상위에 업로드
- Render에 연결하고 GEMINI_API_KEY를 환경변수로 설정

상세 내용은 README.txt를 확인하세요.


Gemini 모델 설정
----------------
- API 키를 입력한 뒤 [모델 불러오기]를 누르면 해당 키에서 실제 사용 가능한 모델을 조회합니다.
- 모델을 직접 입력하지 않으며 드롭다운에서 선택합니다.
- [연결 테스트]는 모델 목록을 다시 확인하고 현재 사용 모델을 화면에 표시합니다.
- 기존 선택 모델을 사용할 수 없으면 ReMap에 적합한 모델로 자동 변경됩니다.


학교망 인증서 안내
------------------
- v4.1.8는 Windows 인증서 저장소를 먼저 사용합니다.
- Missing Authority Key Identifier가 발생하면 인증서 검증을 유지한 호환 모드로 자동 재시도합니다.
- 연결 성공 메시지에 실제 인증서 연결 방식이 표시됩니다.
- 계속 실패하면 학교 전산 담당자에게 HTTPS 검사 루트 인증서의 Windows 신뢰 저장소 설치 여부를 확인받으세요.

v4.1.8 참가자 상태 안내
----------------------
- 학생이 방을 나가거나 연결이 끊기면 현재 참가자·미제출자 수에서 제외됩니다.
- 같은 브라우저가 같은 게임에 곧바로 다시 접속하면 임시 참가자 ID와 토큰으로 기존 정보를 복구합니다.
- [다음 게임 준비]를 누르면 현재 연결된 학생 수는 유지되고, 학생 화면은 새 문제 입력 단계로 전환됩니다.
- 교사 보물상자 현황의 전체 인원은 현재 연결 학생 기준입니다.


Windows 실행 화면과 PC 바로가기
------------------------------
- 실행 화면은 교사 화면과 같은 라운드 카드·그라데이션·입체 그림자 UI를 사용합니다.
- 대표 캐릭터에는 버전 배지를 표시하지 않으며 버전은 화면 하단에서 확인합니다.
- 학교 PC 안내 아래 작성자와 문의 정보가 표시됩니다.
- [PC용 캐릭터 바로가기]를 누르면 ReMap 수업 시작.lnk 자체가 대표 캐릭터 아이콘으로 생성됩니다.
- 학생 PC에서 별도의 BAT 설치를 실행할 필요가 없습니다.
